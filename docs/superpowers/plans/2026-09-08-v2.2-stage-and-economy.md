# v2.2.0 "Stage & Economy" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v2.2.0 of the markdown skill: explicit model tiers, two call cuts, Spectator mode, Protagonist chair, STEELMAN in R2, a market-test demo, and a launch-ready README.

**Architecture:** The product is prose: `SKILL.md` (self-describing Protocol block + numbered orchestration steps) and `agents/*.md` (Claude Code subagent definitions with YAML frontmatter). "Tests" are grep assertions in `tests/check.sh` that pin required and forbidden strings, so every task follows fail → implement → pass. The Protocol block is edited first, then the steps that dispatch it.

**Tech Stack:** Markdown, YAML frontmatter (Claude Code agent files support `model: opus|sonnet|haiku`), bash + grep for checks, git.

**Spec:** `docs/superpowers/specs/2026-09-08-v2.2-stage-and-economy-design.md`

**Tier legend (who executes each task):** `[haiku]` mechanical (git, copy, ls), `[sonnet]` edits and checks, `[opus]` runs that need the orchestrating model (the panel runs in Tasks 10–11 are executed by the main session, not delegated).

## Global Constraints

- Version string is `2.2.0`; CHANGELOG entry dated `2026-09-08`.
- Hard cap R1 + R2 stays. No new rounds. `code` preset stays the only preset.
- Status vocabulary stays frozen at 4. New tags (`STEELMAN:`, `WEAK_POINT:`) are rationale tags, not statuses.
- Agent files stay flat in `agents/` with the `psychodrama-` prefix.
- Public copy (README, CHANGELOG) uses debate / verdict / stage; the word "consensus" appears only in the discovery alias "consensus panel", the `CONSENSUS_STRENGTH` token, the `consensus-runs/` path, and references to the separate `consensus-protocol` skill.
- No Cyrillic in repo files (the Russian triggers live in the author's private config, Task 12).
- Panel cost figures everywhere: **~6-10 calls** panel (6 min, 8 typical, 10 with a full R2), **~9-13** duels, +1 Protagonist, +1-2 figures, +1 external critic.
- Every task ends with `tests/check.sh` passing and a commit.

**Files:**

- [ ] **Step 1: Write the harness**

```bash
#!/usr/bin/env bash
# Assertion checks for the markdown skill. Run from anywhere: tests/check.sh
set -u
cd "$(dirname "$0")/.."
fail=0
must()     { grep -qE -- "$2" "$1" || { echo "FAIL [$1] missing: $2"; fail=1; }; }
must_not() { grep -qE -- "$2" "$1" && { echo "FAIL [$1] present: $2"; fail=1; }; }
count()    { n=$(grep -cE -- "$2" "$1"); [ "$n" -eq "$3" ] || { echo "FAIL [$1] expected $3 of '$2', got $n"; fail=1; }; }

no_cyrillic() { perl -CSD -ne 'if (/\p{Cyrillic}/) { print "FAIL [$ARGV] cyrillic at line $.\n"; exit 1 }' "$1" || fail=1; }

# --- TASK 1 ---
for f in SKILL.md README.md DESIGN.md CHANGELOG.md CONTRIBUTING.md agents/*.md examples/*.md; do
  no_cyrillic "$f"
done
must SKILL.md '^name: psychodrama-protocol$'

# --- END ---
[ $fail -eq 0 ] && echo "ALL CHECKS PASS"
exit $fail
```
